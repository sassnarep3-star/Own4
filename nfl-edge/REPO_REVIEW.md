## 5. Verification performed by this session

1. **15 mechanical integrity checks** (`nfl-edge/scripts/build_stats.py`) — all pass, exit non-zero on failure.
   They test: PF−PA = net points (32/32), league PF = league PA, W = L, offence = defence league-wide for pass
   yards / pass TDs / rush yards / rush TDs, offence points = standings PF, defence points = standings PA,
   archive W-L-T/PF/PA = official standings (32 clubs, 0 mismatches), per-week game counts, Week 10 slate shape,
   every game has an official URL, injury sections cover every Week 10 club, every injury row sourced.
2. **Site verification** (`nfl-edge/scripts/verify_site.py`) — 22 pages, 889 table rows all carrying a source
   link, 628 local links resolved (anchors included), 1,093 external links all `https`, JSON parse checks,
   published headline numbers compared against the JSON to catch drift, and a scan for placeholder text.
3. **Source re-reads on 2026-11-12:** standings, team stats (6 pages), schedule week 8/9/10, injuries week 10,
   two official news items, one club roster page, and one team depth-chart URL (404).
