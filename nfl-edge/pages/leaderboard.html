Cash value is zero by policy: a cash prize on an unvalidated model turns research into advertising. Points are a ranking device, nothing more (decision D2).

How a strategy enters the competition

  1. Write the rule down: the exact trigger, the market, and the size rule.
  2. Register it in the strategy catalogue and in the gate file, with a version number, before running it.
  3. Run it once on the holdout with the frozen configuration and publish the result whatever it is.
  4. Only a full gate pass earns points. A change to the rule starts a new version with its own line in the catalogue.
