Own line, official line, residual

Order of publication is the registered order: side, then total, then moneyline. For each graded 2026 game the model's fair line is published beside the officially sourced posted line with the residual between them. The residual is a market-divergence measurement, never CLV: the posted line's capture time is unpublished, so this build cannot show that it preceded kickoff.
