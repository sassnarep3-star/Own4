Verification

Reproduce every number

The whole build is eight commands, in order. Each writes a JSON file that the next one reads, and none fetches anything:

python3 nfl-origination-lab/engine/parse_availability.py
python3 nfl-origination-lab/engine/corpus.py
python3 nfl-origination-lab/engine/evaluate.py
python3 nfl-origination-lab/engine/price_policy.py
python3 nfl-origination-lab/engine/depth.py
python3 nfl-origination-lab/engine/governance.py
python3 nfl-origination-lab/engine/registers.py
python3 nfl-origination-lab/engine/build.py
python3 nfl-origination-lab/engine/verify.py

Then verify.py asserts the properties below and exits non-zero if any fails. It also re-runs the walk-forward with a poisoned future and asserts the predictions do not move — the only test of no-lookahead that means anything.
