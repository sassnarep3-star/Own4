Pre-registration

The registration is the commit

Every rule below was written down and committed before the code that scores it produced a number. The commit hash is the registration; if a rule changes, the version string changes and the old block stays. One correction is recorded in the file itself: the total-market threshold was first described as the rounded 2025 median, which was false, so the description was corrected before any score existed and the correction is kept.
