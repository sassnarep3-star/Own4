Singles shadow baseline (pre-registered)

A simple team-strength model, frozen before Week 11 kickoff. Shadow only: recorded and graded later, never staked.

Registration

Rule text and code are frozen at commit 64a20e8 (2026-11-15T23:28:36Z). The forecasts below were produced after that commit by nfl-readiness/prereg/shadow_v1.py. Read the rule: SHADOW_BASELINE_v1.md.

  • Model: rating = (points for − points against) ÷ games (standings only). Home margin = rating difference (no home-field term). P(home) = Φ(margin ÷ 13.5). The 13.5-point sigma is an unsourced assumption (F-R10).
  • Controls per game: coin-flip (0.50 each side; Brier 0.25), favourites-only (higher rating), seeded random pick.
  • Skill claims: none. Gate: 300 graded games before any claim (Q-R06). Graded so far: 0.
