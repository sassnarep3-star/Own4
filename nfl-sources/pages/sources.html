Method for every transcription

Read the official page, copy the printed values in the printed order, one file per week, and hash the file. Where a page prints something internally inconsistent, the inconsistency is copied and flagged rather than repaired: see Flagged for the three cases — the bye-week records printed as current records, week 1's Wednesday-dated "Sunday Night Football" section, and the Colts game-centre strip showing a Miami score that does not match the schedule page.
