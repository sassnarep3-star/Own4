Options

  • A — one canonical workspace. Owner picks the strongest implementation from the matrix; the others stay published as archived evidence (nothing is deleted; each keeps its namespace and PR history).
  • B — canonical + satellites. One workspace owns the stores; the others link into it for their specialized extras (e.g., nfl-ledger’s promotion/demotion unit tests, nfl-command-center’s repo audit).
  • C — keep all four independent. No consolidation; reviewers read all four (status quo, highest review cost).
Recommendation (a suggestion — the owner decides): Option B, with nfl-core as the store-of-record: it is the only implementation whose price store actually holds opening and closing numbers with settlement (81 open / 489 close vs 84, 0 and 39 rows elsewhere), the only one whose results feed is re-verified against the official standings inside its own verifier, and it publishes the resolved spread convention that the other workspaces’ flags still list as open. Peer workspaces would remain published and linked — nothing discarded. If the owner prefers another workspace as canonical, the same matrix supports that choice.
Status: proposed. This page implements nothing. Until the owner marks S-C11 “chosen” on the suggestions board, all four workspaces remain as published.
