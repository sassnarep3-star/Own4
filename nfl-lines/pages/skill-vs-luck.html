Skill vs luck

What chance alone would have produced, next to what actually happened.

The question this page answers. A bettor with no skill whatsoever, taking the same prices, will sometimes show a positive return purely by chance. The only honest way to separate skill from luck is to work out what luck alone would have produced and compare. That is what the simulation below does: 20,000 runs per strategy, each run facing the same prices in the same order, winning with the probability implied by those prices.

Reading the table

  • Band width is how much of the observed result chance alone can account for. At 303 bets it is about 22 percentage points wide; at 3,251 bets it is about 6. Sample size is the only real cure.
  • Bets needed to prove it is the sample required to detect the observed edge at 80% power and a 5% significance level. Where a strategy shows no positive edge the cell reads "n/a".
  • Verdict is "inside" when the observed return sits within the 95% no-skill band. Every strategy on the board is inside.

Calibration: a second, luck-resistant test

Return on investment is noisy. Calibration is not: if the model says a team wins 70% of the time, that team should win about 70% of the time. The model's weighted reliability error is 0.00088 and its Brier score is 0.2265 against a naive baseline of 0.2473, so the model improves on guessing and is honest about its own confidence. It is still worse than the market, whose Brier score is 0.2106. A model can be well calibrated and still have nothing to sell — that is exactly the situation here.
