Demotion gate

A live strategy has to be able to lose its status. This gate does that, and it is deliberately one-directional.

A demotion gate can only remove candidates. Applying it to results that already exist cannot create a winner, so no lookahead is introduced. A promotion gate designed at the same moment would be a different matter and is not proposed here.

No strategy in this repository has ever been live: all 15 are published as paper. The gate is therefore a specification with a known answer under current data, which is what makes it testable before it is trusted.
