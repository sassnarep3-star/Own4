2. The two blockers are now answers, not blanks

Prices: nfl.com/odds/ and nfl.com/betting/ both return the league's own 404 page (both read inside 2026-11-16T01:36:08Z), and the official Game Summary contains no price. So 'no official price source' is no longer an open research question; it is a settled negative, and what remains is a policy choice (CD-02). Depth: the sampled club depth-chart path 404s and no per-player snap table appears in the four game-book chunks read, so '2nd/3rd/4th string' still has no official basis — and the site should keep refusing to build it from jersey order. 3. The Game Book unblocks the half of the programme that was calling itself stuck

For a sampled completed fixture the league publishes a dated PDF carrying both clubs' official lineups (22 slots), substitutions (26 each), Not Active lists (6 each), a Did Not Play block, game-day weather, the roof/surface phrase, officials, attendance, full statistics, drives and play-by-play with timed in-game injury updates. A second fixture one week later carries its own. That is enough to build the results feed, the venue/surface context, the inactives record and the 'who actually started' half of the availability graph — from official sources, with no new licence. It is also the reason the label join in this namespace closes at all: 20 of 24 report rows join confidently (2 ambiguous, 2 unaccounted). Evidence ↗

4. And it comes with two conditions nobody recorded

The document is post-game — it contains final statistics — so it can grade a forecast and can never feed one. It also prints a use restriction: media coverage only, any other use prohibited without written league permission. Two namespaces already publish transcribed lineups; the repository's own registers describe game books as the source they need, and none of them notes either condition. Flags DC-04 and DC-05 ↗

5. The corpus number moves the leaderboard from 'soon' to 'next season'

From the league's standings at this session's clock: 148 fixtures credited (147 decisive, 1 tied), ΣW = ΣL = 147 and ΣPF = ΣPA = 6824, so the identities close. A season holds 272 fixtures. Any gate demanding n ≥ 300 graded fixtures is therefore unsatisfiable inside 2026, and the brief's '136-game log' is exactly half a season (136) — the only arithmetic from official numbers that reproduces it. Either the gate, the unit (club-games: 296 today) or the timeline changes; that is a decision, not a data gap. Corpus arithmetic ↗

6. What to do first

  1. Write three verdicts — CD-02 (price policy), CD-06 (gate vs season), CD-01 (one canonical surface). Each is a sentence and each releases a family of work.
  2. Build the collector before any model (CD-04): dated captures with raw bytes and a hash, because today the site cannot distinguish 'absent from the source' from 'lost in the render' — DC-05 is that failure, live, in one of this namespace's own joins.
  3. Then the join at scale (CD-07): designation → game-book status for every fixture, with Wilson intervals and n, and no legacy percentages imported.
  4. Only then the leaderboard (CD-10, CD-14): skill division with the trial count published, staking kept in a separate column, and no reward denominated in a backtest.

This console has 147 of 15 verdicts written. Until they exist, the honest status line for the whole programme is: specification complete, decisions pending.
