Method, sources & limits

How every number on this site is produced, what was read to produce it, and what this session did not read. The last section is the one that matters: a verification page that does not state its own limits is not a verification page.

Pipeline

python3 nfl-reconciled/engine/reconcile.py → validates the transcription and writes four derived artefacts
python3 nfl-reconciled/engine/build_review.py → collects every workspace’s flags into one index
python3 nfl-reconciled/engine/build_site.py → renders these pages
python3 nfl-reconciled/engine/verify_site.py → fails if any row lacks a source, any link is broken, or any page lost its footer

Standard library only, no network, no environment-dependent output. CI runs all four and then a determinism gate: a rebuild that changes a committed page fails the build.

The transcription is the only thing that can be wrong

Every published figure is computed from data/official_facts.json, so a transcription error is the only way a number here can be wrong. The engine therefore refuses to publish if the transcription fails an identity the league’s own numbers force:

  • all 32 clubs present, and league wins equal league losses;
  • league points-for equal league points-against;
  • the Week-10 fixtures plus the four bye clubs cover exactly 32 clubs with no overlap;
  • 32 clubs − 4 byes ÷ 2 ≡ the number of fixtures itemised (this check caught a transcription error of this session’s own);
  • a game marked FINAL carries a score, and a game not marked FINAL carries none.

Those checks live in check_facts() and exit non-zero. They are not decoration: the fourth one failed on the first draft of this file, which claimed 16 Week-10 fixtures where the arithmetic forces 14.

What this session did NOT read

  • Chunks 2–7 of the injury report. Only WAS, NYG, NE, DET, KC, ATL, MIN, GB and the start of JAX were read. The 347-row claim therefore rests on the capture’s own data plus a hand count of 8 clubs and 18 cells — not on all 28 clubs. The other 20 clubs are neither confirmed nor denied.
  • The 2026 rulebook. No kickoff or onside-kick rule is asserted anywhere on these pages (conflict RC-14).
  • Any betting price. The league publishes none, so no price is printed and none is inferred (conflict RC-11).
  • Any club depth chart. No ordered depth rank is asserted (conflict RC-12).
  • The other 30 workspaces’ contents. Their artefacts were read as data; their source claims were not independently re-verified. Where this site cites a peer number it names the file.

Rules this workspace follows

No value without a source
A settled row must carry an official URL; a row with no official number is REVIEW and prints null.
No inference
A game not marked FINAL prints an em dash. A missing cell stays blank. A club on bye is not “injury-free”.
No silent disagreement
Every conflict between workspaces is a numbered row on the conflict register, with the peers named.
No editing of peers
This workspace reads other workspaces’ files and never writes to them.
Reproducible
Pages are generated from the data; CI rebuilds them and fails on any diff.
