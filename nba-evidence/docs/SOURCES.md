# Primary source register

- [NBA: NBA.com/Stats Frequently Asked Questions](https://www.nba.com/stats/help/faq) — checked 2026-11-02. Access limitation; no bulk scraping or licensed-feed claim. Small factual score extracts are separately linked to their official pages.
- [NBA Official: Rule No. 5: Scoring and Timing](https://official.nba.com/rule-no-5-scoring-and-timing/) — checked 2026-11-02. Regulation duration; the same page specifies five-minute overtime periods. This is not a sportsbook settlement rule.
- [NBA: Stat Glossary](https://www.nba.com/stats/help/glossary) — checked 2026-11-02. Official terminology reference. Model features and PRA arithmetic are defined by this project, not official sportsbook lines.
- [bet365: Basketball Rules](https://help.bet365.com/s/en/sportsrules/basketball) — checked 2026-11-02. Operator-specific settlement context only. The page also requires relevant players to be dressed and see court time, unless specified otherwise. Never generalize to all operators or jurisdictions.
- [FanDuel: What is a Same Game Parlay or SGP Plus?](https://support.fanduel.com/s/article/What-is-a-Same-Game-Parlay-or-SGP) — checked 2026-11-02. Existence and definition of SGP; not a quoted price, eligibility guarantee, or evidence of profitability.
- [NIST/SEMATECH: Mean Vector and Covariance Matrix](https://www.itl.nist.gov/div898/handbook/pmc/section5/pmc541.htm) — checked 2026-11-02. Sample covariance definition used in Pearson correlation. Does not verify any NBA correlation estimate.
- [NIST/SEMATECH: Proportion Confidence Interval](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/propconf.htm) — checked 2026-11-02. Wilson interval reference; binomial intervals require independent trials and are not used to certify correlated parlays.
- [scikit-learn project: TimeSeriesSplit](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html) — checked 2026-11-02. Chronological evaluation principle. This project implements its own date-split, not the library estimator.
- [scikit-learn project: Probability calibration](https://scikit-learn.org/stable/modules/calibration.html) — checked 2026-11-02. Separate proper scores from calibration diagnostics; no calibration claim from Brier alone.
- [scikit-learn project: Metrics and scoring: quantifying the quality of predictions](https://scikit-learn.org/stable/modules/model_evaluation.html#brier-score-loss) — checked 2026-11-02. Probability score definition, not a sports edge test.
- [National Bureau of Economic Research: ... and the Cross-Section of Expected Returns](https://www.nber.org/papers/w20592) — checked 2026-11-02. Multiple-testing risk; the page discusses a t-ratio above 3 in its financial-factor setting. That cutoff is not transferred to NBA as a validated threshold.
- [SSRN / Journal of Portfolio Management: The Deflated Sharpe Ratio: Correcting for Selection Bias, Backtest Overfitting and Non-Normality](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2460551) — checked 2026-11-02. Selection bias and non-normal returns. DSR is not computed here because there are no verified wager return series.
- [NBA: Official scoreboards, January 1–8, 2025](https://www.nba.com/games?date=2025-01-05) — checked 2026-11-02. 62 final scores and overtime labels. Display order is retained as team1/team2; home designation is not inferred for the whole sample.
- [NBA: Boston Celtics vs Oklahoma City Thunder, January 5, 2025 box score](https://www.nba.com/game/bos-vs-okc-0022400487/box-score) — checked 2026-11-02. Player minutes, points, rebounds and assists; team totals used as arithmetic cross-checks. DNP rows excluded, not converted to zero-stat performances.
- [NBA: Brooklyn Nets vs Milwaukee Bucks, January 2, 2025 box score](https://www.nba.com/game/bkn-vs-mil-0022400465/box-score) — checked 2026-11-02. Player minutes, points, rebounds and assists; team totals used as arithmetic cross-checks. This is a two-game convenience sample, not a player-time-series panel.
