How the line is made

Probability reference ↗
offₜ = (prior points scored + k·league mean) / (prior games + k) defₜ = (prior points allowed + k·league mean) / (prior games + k) E[team1] = (off₁ + def₂) / 2 E[team2] = (off₂ + def₁) / 2 margin = E[team1] − E[team2] total = E[team1] + E[team2] p(team1) = frozen logistic(margin) fair decimal = 1 / p

k = 5; training league mean = 113.6304. Half-point display lines use floor(x)+0.5. No venue or context adjustment is inferred.
