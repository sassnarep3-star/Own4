How to reproduce every number

python3 nfl-hq/build_data.py rebuilds every official snapshot, the derived deficiency read and the verification receipt · python3 nfl-hq/build_site.py regenerates this site · python3 nfl-hq/verify.py fails the build if any table row lacks a source link or any local link is broken.

Source of the archived game and market data: nflverse/nfldata ↗ · The NFL publishes no betting lines, so every spread, total, moneyline and price on this site is labelled third-party.
