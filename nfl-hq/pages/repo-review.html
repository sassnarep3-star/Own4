Irregularities found in the review

Every item below is published on the Flagged for Review page with its source links. None of them blocks the site.

The findings that matter

  • The committed official snapshot was one game stale. The standings and team stats committed on 2026-11-12 predate the Thursday night game, and the repository published them without noticing. This session re-read both pages and published the current values, and the diff is now a committed artefact.
  • The Monday-night injury report was published as empty. On 2026-11-12 the Chargers-Ravens game carried no player rows and the note said the page stated no injuries reported. By 2026-11-13 the same game carried 26 rows. A blank is not a clean bill of health and it was published as one.
  • The official injury report is rewritten every day and nothing in the repository detected that. The diff is now published, but no scheduled fetch job exists yet.
  • Every market value in the repository is third-party, because the NFL publishes no betting lines. This is labelled throughout and is not a defect, but it is the largest single dependency in the research.
  • 16 overlapping NFL namespaces each carried their own copy of the questions, suggestions and flagged pages, and more were still being added by peer sessions while this site was built.
