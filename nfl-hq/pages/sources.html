The rule this site follows

Every table row carries a link to the page it was read from. Every value that cannot be confirmed from an official source is published as a blank cell and listed on the Flagged for Review page. No value is ever inferred, estimated or filled in from memory. The verifier fails the build if any row has no link, and it reports every blank so the blanks can be checked.
