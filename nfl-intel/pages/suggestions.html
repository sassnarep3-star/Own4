Suggestion register — review here, decide first, implement later

Nothing on this page is implemented. Every item is a proposal. A human reviewer must set status and decision per item; only then does it become work. This page is the “choose the best path before implementing” gate.

How to review (protocol)

  1. 1. Reviewer reads the suggestion + linked question(s).
  2. 2. Reviewer checks the discovery suggestion and any prerequisites are satisfiable.
  3. 3. Reviewer sets status and records decision + date in the review UI (or by PR comment).
  4. 4. Accepted suggestions become tasks on COORDINATION.md with explicit file scope.
  5. 5. Rejected/deferred stay in the register for audit; never silently deleted.
