Leaderboard — signal vs staking

A lucky staking run cannot move a strategy up while its signal fails.

Rules

  • Ranking uses signal columns ONLY. Staking columns are displayed but never change rank.
  • A strategy is reward-eligible only if signal gates pass AND n >= 300 graded selections (G2).
  • Staking results (ROI, bankroll path) cannot offset a failed signal gate; a strong staking run with a failed signal is labelled "signal fail — staking ignored".
  • Missing staking or price data is blank and makes the strategy paper-only, never live.
