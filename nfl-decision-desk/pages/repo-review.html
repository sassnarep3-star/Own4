Build and verification

The workspace is generated by six builders in order, then checked by a verifier that fails on: a table row without an https source, a dangling local link, a missing page, or a rebuild that changes a committed page. Run from nfl-decision-desk/:

python3 engine/build_corpus.py
python3 engine/model.py
python3 engine/leaderboard.py
python3 engine/prices.py
python3 engine/correlations.py
python3 engine/availability.py
python3 engine/fixtures.py
python3 engine/governance.py
python3 engine/site.py
python3 engine/verify.py

Scope discipline

No peer namespace was edited. COORDINATION.md is append-only, and the only shared file touched is the root navigation, additively, through the generator's NAV list. Peer files were read for verification and never rewritten.

Research notebook, not advice. No wagering is offered. Staking figures use an assumed −110 price and are labelled hypothetical everywhere. Numbers come from sources listed on each row; values that could not be sourced are left blank and are listed on the Flagged for review page. Gambling help: NCPG.
