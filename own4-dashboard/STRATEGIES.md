## Validation gates

A strategy is VALIDATED only if every applicable gate is PASS. N/A is ignored. Any FAIL or UNVERIFIED blocks validation and leaves ROI/CLV/profit/reward blank.

| Gate | Name | Pass criterion | Official source |
| --- | --- | --- | --- |
| G1 | Official provenance | Every numeric input traces to an allowlisted official NBA/league URL with a retrieval date. | [Official](https://www.nba.com/stats/teams/advanced?Season=2025-26) |
| G2 | Data completeness | All fields required by the strategy are present and verified; no blank/unverified inputs. | [Official](https://www.nba.com/games?date=2026-11-04) |
| G3 | Minimum sample size | n >= 200 independent settled observations before any strategy-level performance claim. | [Official](https://www.nba.com/games?date=2026-10-23) |
| G4 | Out-of-sample evaluation | Evaluation data must not have been used to build or calibrate the model. | [Official](https://www.nba.com/stats/teams/advanced?Season=2025-26) |
| G5 | Significance after multiple testing | Permutation test with Benjamini-Hochberg FDR q < 0.05 over the full tested family. | [Official](https://www.nba.com/stats/help/glossary) |
| G6 | Skill-vs-luck (luck removal) | Positive holdout Brier skill score AND exact binomial p < 0.05 on holdout winner accuracy. | [Official](https://www.nba.com/games?date=2026-11-01) |
| G7 | Economic validity | Verified official market odds / vig available so edge, CLV and net ROI can be computed. | [Official](https://www.nba.com/news/nba-extends-u-s-betting-data-partnerships-with-sportradar-and-genius-sports-group) |
| G8 | Parlay / prop correlation guard | Leg correlations measured from official data; dependent legs explicitly modelled (not assumed independent). | [Official](https://www.nba.com/games?date=2026-11-04) |
| G9 | Walk-forward stability | At least 3 chronological out-of-sample folds, all with non-negative skill. | [Official](https://www.nba.com/games?date=2026-10-28) |
| G10 | Reproducibility | All published numbers regenerated by committed scripts from committed raw official snapshots. | [Official](https://github.com/sassnarep3-star/Own4) |

## Research findings

- The [prior-season rating model](https://www.nba.com/stats/teams/advanced?Season=2025-26) reached `0.780`
  winner accuracy in the training window but only `0.476` on the
  chronological holdout (n=21), with binomial p =
  `1.0000` and Brier skill score
  `-0.064` — [official settled scores](https://www.nba.com/games?date=2026-11-01).
  Under the pre-registered luck-removal rules it is **not skill-based**.
- The naive "pick the better 2025-26 record" baseline reached
  `0.710` over all
  62 games, higher than the model's `0.677`.
- Same-game parlay legs are measurably correlated (see `CORRELATIONS.md`), so independence
  must not be assumed. Where a joint model cannot be verified, the price is left blank.
- Player-prop fair lines require game-level distributions, which are not available from free
  official NBA pages — the fair-line cells are blank, only verified season baselines are shown.
