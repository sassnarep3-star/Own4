Own4 — NFL line-origination research

Own4 is a line-origination research repository. The active project is the NFL Command Center: official NFL data read line by line from NFL.com, our own originated lines, gated strategies, a leaderboard that awards nothing until a strategy proves it is not luck, and a reviewable register of questions, suggestions and flagged irregularities. How every number on this site is produced

python3 nfl-hq/build_data.py reads the official NFL.com pages and writes the normalized data plus the verification receipt · python3 nfl-hq/build_site.py rebuilds the site from that data · python3 nfl-hq/verify_site.py fails the build if any link is broken or any table row has no source link · python3 nfl-hq/build_root.py rebuilds this page. Everything is plain static HTML with no framework, no tracking and no network calls.
