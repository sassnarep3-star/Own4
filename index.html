How to check any number

  1. Pick a row in any table. It carries the exact official URL it came from, or a link to the committed data file.
  2. Rebuild locally: cd nba-lines && python3 collect_official.py && python3 engine.py && python3 audit.py && python3 build.py && python3 verify.py.
  3. Anything that could not be verified is blank on the site and listed on the flagged page — never inferred.
