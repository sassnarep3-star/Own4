09 / Repository audit

This repository was not built for rental law.

The existing root project is an unrelated NBA research/dashboard site. The rental review is deliberately served from its own directory and does not replace or modify the prior work.

PRE-EXISTING PROJECT

Root site preserved

  • The root index.html, generated NBA pages, NBA documentation, and existing canonical-site validation workflow belong to a separate project.
  • A repository search before adding this site found no existing rental-law analysis or tenant records.
  • No NBA HTML, generator, documentation, workflow, or root Pages configuration was changed for this deliverable.
ISOLATED DELIVERABLE

One new path

  • All rental-site pages, source registry, styles, and checks are under rental-sf/.
  • The site is static HTML/CSS with no backend, analytics, external JavaScript, or private tenant data.
  • Pages navigation and assets use relative paths so the subdirectory works under the repository’s GitHub Pages URL.

Pages configuration checked before publication

Existing Pages uses the main-branch root.

The GitHub Pages API reported the repository’s public site using the legacy Pages build, source branch main, path /, and HTTPS. Under that configuration, the isolated directory is served at the repository subpath after the change is merged and Pages rebuilds:

https://sassnarep3-star.github.io/Own4/rental-sf/

The root remains the pre-existing NBA site; the rental landing page is /rental-sf/. No Pages settings or existing workflow changes were required. After merge, confirm the deployment status and open the URL in a browser; a successful repository build alone does not prove the Pages deployment is live.

Integrity controls

Scope and privacy checks

  • Only generic unit labels are used; tenant names and initials are omitted from public files.
  • Owner-supplied amounts/dates are labeled unverified and separated from legal conclusions.
  • Every data-table row links to an official government source for the legal rule it discusses; the site says expressly when that source cannot authenticate private tenancy facts.
  • The build verifier checks internal links, registered official-source links, HTTPS, and a source link in every table row.
