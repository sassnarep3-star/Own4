Method

How the sweep was run, what is transcribed, what is computed, and where it can be wrong.

Probe rules

  • Route L (league): one fetch per https://www.nfl.com/teams/<slug>/depth-chart/ for all 32 slugs from nfl.com/teams/, plus the league-wide /depth-charts/. Result recorded from the rendered body: the league's “404 – Flag on the Play.” text is the 404 evidence (no HTTP status is exposed by the fetch tool — DS-13).
  • Route C (club): one fetch per https://www.<club-host>/team/depth-chart. Every club host is copied from the league's own “View Full Site” link — none is assumed.
  • Window: all reads on 2026-11-17 UTC, one session pass. The fetch tool exposes no per-call clock, so the window is recorded rather than per-row timestamps (same convention as nfl-collector's SUG-12 A).

Transcribed vs computed

  • Transcribed per row: result, structure, heading, printed as-of date, self-label, slot row counts, shared/empty rank-1 observations, notes. Each is a reading of the page named in that row's source link.
  • Computed at build time: every aggregate on the Dashboard and Findings pages (counts of 404s, present, tables, dated, shared/empty slots, totals, chart ages). The generator derives them from the JSON; engine/verify.py recomputes and fails the build if any published aggregate disagrees with the data.

Limits (stated, not hidden)

  • No per-fetch clock (window only); no HTTP status codes (body evidence only).
  • Slot counts are counts of the rendered table rows as read; a club that edits its page after 2026-11-17 will differ — re-run the sweep to refresh.
  • Houston's image chart is not transcribed: its row fields are blank by rule (DS-02).
  • The sweep records what pages print. It does not verify that printed depth matches who actually played — that requires official Game Book participation, tracked in nfl-collector.
  • No verdict is taken on SG-C (building the deficiency feature): that decision stays with the owner; this sweep is the evidence needed to make it.

Rebuild & verify

python3 engine/build.py && python3 engine/verify.py — standard library only. Verify fails on: row counts ≠ 32, missing source links, aggregates disagreeing with data, broken internal links, or a non-deterministic rebuild.
