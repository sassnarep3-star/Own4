Headline result

No edge is claimed. No strategy clears the pre-registered gates; zero reward points are awarded. The model is a v1 research baseline with flagged assumptions (home field +2.0 pts, uncalibrated logistic scale, league-average total). Because the NFL publishes no odds, no ROI or CLV is computable anywhere on this site. The value of this release is the verified data, the public gates and the honest scoreboard — not a pick.
