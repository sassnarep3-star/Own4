⚑ Flagged for review

Every irregularity and every value that could not be confirmed from an official source. None of these blocks publication; all of them block a claim. Each entry carries the official page and the repository file behind it so it can be reviewed directly.

13 flags: 4 high, 6 medium, 3 low. They fall into three kinds — data that is absent (prices, player logs, availability), data that is partial (36 uncaptured games, 56 un-re-fetched rows), and data that is present but internally odd (the +/- sum). The third kind is the most interesting, because it is the only one an official page itself could resolve.

How to request a change
