# San Francisco rental research

Static GitHub Pages project at `/rental/` (standalone to preserve existing repository dashboards). Run `python3 rental/build.py` and `python3 rental/verify.py`. The latter checks local paths, official-domain links on each table row, arithmetic, and reproducible generation. It does not prove a link supports a claim, check external sites, or constitute a legal review.

Sources and limitations appear alongside each finding and on Flagged for Review. User-reported case facts have not been independently verified; dollar scenarios are conditional arithmetic. No name, initials, precise address, contact information, or original documents are published. Dates and amounts retained as requested may nonetheless create re-identification risk on this public repository. This is not legal advice and no lawyer or tenant has reviewed or approved the work.
