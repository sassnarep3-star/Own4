Method. (1) Each official page was read in full via the platform page-read tool; every data table was transcribed verbatim to CSV in evidence/ (cells as published; documented abbreviations only). (2) engine/compute.py re-parses the evidence — and the two peer capture files, hash-checked first — with code that shares nothing with the transcription, and writes data/*.json. (3) engine/build.py renders this site from those JSONs. (4) engine/verify.py gates the publication.

Transcription conventions

  • Practice status: DNP = “Did Not Participate In Practice”, LP = “Limited Participation in Practice”, FP = “Full Participation in Practice” (the three strings the page publishes).
  • Game status: the cell exactly as published (Out, Questionable, Doubtful) or empty — empty is the page's blank and is never read as “available”.
  • Player URLs are kept per row so identity is the slug, not the display name (F-WS-08).
  • Capture_a's raw-HTML parse unescapes HTML entities before joining; display-name variants across reads are classified as identity pairs, not roster moves.

Rows are transcribed from official pages read on 2026-11-19 via the platform page-read tool; counts are machine-derived from the evidence files by an engine that shares no code with the transcription. No price, edge, ROI, win-rate or ranking is claimed anywhere on this site (repository publication policy). Blank cells are blanks as published, never inferred values. Flagged items do not block publishing; they block claims.
