Policy

  • A source appears here only if its page text was actually read. A search result is not a source.
  • Where a page publishes a value, it is transcribed. Where it does not, the row is absent and the absence is the finding — this is why the venue table has holes.
  • Two sources disagreeing is published as a conflict with a stated resolution, never averaged or silently resolved. See verification and R-03.
  • Live pages move. Every figure carries the capture clock above, and no count is presented as durable.

Reproduce

Four commands, no dependencies beyond Python 3:

cd nfl-verify/engine
python3 derive.py
python3 readiness.py
python3 build_site.py
python3 verify.py

derive.py reads only data/observations.json. Editing that file and re-running changes every published number; editing a page by hand fails the determinism gate in CI.
