NFL Command Deck — decision readiness

A frozen forecast evaluation, a repository audit, and the questions that must be answered before any line is originated for money.

This is one additive workspace in a repository that already holds 41 overlapping NFL workspaces. It does not restate their numbers as new analysis. It does three things: it recomputes a pre-registered forecast evaluation from the committed official corpus, it audits the repository and the 73-row requirement register against the artifacts they cite, and it publishes what is still missing and what would clear it.

Reading rule used everywhere on this site: CAPTURED means a committed official capture with a re-checked SHA-256; DERIVED means computed by a named script here; anything else is blank with a reason.

What this workspace will not claim

  • No ROI, CLV or staking result. There is no official price source (RF-14). An assumed −110 price is not used anywhere.
  • No injury adjustment to any forecast. One week of availability exists; an ablation needs a history (Q-07).
  • No parlay or prop-combo probability. Under dependence, marginal probabilities cannot be multiplied (Q-09).
  • No 'verified today'. nfl.com is unreachable from this build environment (RF-01).
  • No starter claimed from a depth chart. The club's next name is published; who played is blank (availability).
