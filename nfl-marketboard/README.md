# nfl-marketboard

Own-line origination for the 2026 NFL season, graded against officially sourced results.

The whole workspace is reproducible from its own code and its own checked-in raw data:

```
python3 engine/build.py     # raw/ -> data/*.json   (reconciliation, lines, prices, ...)
python3 engine/site.py      # data/*.json -> *.html (16 pages)
python3 engine/verify.py    # publication gate: source links, local links, nav, footer
```

`engine/build.py` must be run from this directory: the price archive is read at
`../nfl-hub/data/source/games.csv`.

## What is here

| File | What it is |
|---|---|
| `data/raw/results_2026_official.csv` | 137 official final scores, transcribed from nfl.com, one game URL per row |
| `data/raw/standings_2026_official.csv` | official 2026 standings through Week 10 — the reconciliation target |
| `data/raw/standings_2025_official.csv` | official 2025 FINAL standings — the pre-season prior |
| `data/raw/injuries_week10_official.csv` | official Week 10 injury report, 300 rows, verbatim |
| `data/raw/starter_replacements_official.csv` | the only officially *named* replacements |
| `data/*.json` | engine output; regenerated by `engine/build.py` |
| `engine/content.py` | questions, suggestions, flags, repo review, source register |
| `engine/site.py` | page renderer |
| `engine/verify.py` | publication gate |

## Rules this workspace holds itself to

1. Every `<tr>` inside a `<tbody>` carries an https link to the source it came from.
   `engine/verify.py` fails the build otherwise.
2. A value that cannot be confirmed from an official source is published **blank** and
   flagged — never inferred, never filled in.
3. The NFL publishes no odds. Every market price on this site is third-party
   (nflverse/nfldata, CC BY 4.0) and is labelled as such on the row that uses it.
4. Negative results are published as results. The current model loses to the market on
   both markets it originates; that is on the front page, not buried.

## Headline finding

Originated lines are **worse** than market lines on the 105 walk-forward graded games:
spread MAE 9.383 vs the market's 8.814 (paired p = 0.138); total MAE 11.112 vs 10.357
(paired p = 0.046). No strategy passes the gates; 0 of 1,000 reward units are awarded.

Research only. Not wagering advice.
