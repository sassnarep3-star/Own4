The thing the brief asks for that does not exist

The brief asks for defensive and offensive deficiencies tracked as "2nd, 3rd or 4th string backups replacing starters". What cannot be said

  • No string rank. No official depth chart, no snap counts — see above.
  • No size of effect. The official report says a player is out; it does not say how many points that costs. The injury adjustment on the own lines page is a disclosed assumption published as a band, and correlation C9 (injury vs margin) is blank because no historical injury archive exists.
  • Absence is not health. MIN, GB, LA, AZ, LAC, BAL have no designation block in the official per-game report this week. That is recorded as a gap (flag F-04), never as "available".
  • No history. nfl.com/injuries/ serves the current week only, so no injury effect can be back-tested. Suggestion S04 starts capturing snapshots weekly.
