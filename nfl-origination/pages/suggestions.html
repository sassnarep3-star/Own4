Suggestions & decisions

A decision board, not a to-do list. Each suggestion carries the context, the options considered, the evidence available, the cost, the risk, its prerequisites and a recommendation — so a path can be chosen before anything is implemented.

The recommended path

This is the order a reviewer can actually work in. The first group contains the decisions that gate everything else: until the legal position, the skill definition, the canonical dashboard and the headline framing are settled, every other choice can be invalidated by them.

  1.   2. Week 1-2 — start the free clocksS04 Start capturing the official injury report into a dated snapshot every week, S12 Keep this namespace's verification harness as the merge gate for every future session, S21 Make the coordination board machine-checked, S15 Publish a forward-record ledger so future results cannot be back-fitted
  3. Then decide whether this is a betting project at allS01 Buy or license an archived NFL odds history, S06 Buy archived same-game-parlay prices before building any prop strategy, S11 Establish whether the archive's line is the close or an earlier snapshot
  4. Only if yes: buy the rest of the inputsS09 Obtain a player-level game log and a snap-count feed, S03 Publish only article-confirmed lineup changes, or buy a depth-chart feed, S05 Convert injuries into points with a measured model rather than an assumed weight
  5. Hygiene and small winsS08 Review the third-party archive's licence before anything is redistributed, S14 Test the rest term properly before believing it, S20 Model the total separately from the margin, S13 Add a weather term, but only for outdoor games with a verified forecast, S18 Increase the sample before making any claim about 2026 specifically, S19 Add a one-screen 'what changed since last week' page
  6. Blocked until the inputs existS22 Publish a live in-week injury-adjusted line

The one sentence version

Settle the skill definition (S07) and the legal position (S02), then decide whether this is a betting project at all (S01). Until a real price history exists, everything on this site is a forecast, not a bet — and it should keep saying so.

S01Buy or license an archived NFL odds history Data acquisition DECIDE NOW
Context

Options

S07Adopt a written skill definition and reward rule before any reward is paid Governance DECIDE NOW
Context
The proposal on this site: a strategy is skilful only if (a) it survives Benjamini-Hochberg across every test run including placebos, (b) its week-clustered 95% CI on ROI is entirely above zero, and (c) no single season supplies more than half its profit.
Options
  • Adopt the proposal as written
  • Adopt a looser rule (point estimate above zero)
  • Adopt a stricter rule (require live, forward-recorded results too)
Evidence
Every strategy tested here fails at least one of (a)-(c); so does the placebo-free version of the screen. The rule rejects our own best result.
Cost
Zero.
Risk
A loose rule pays for luck. The looser option above would have paid two strategies here, both of which the placebo test shows are noise.
Prerequisites
S02
Recommendation
Adopt as written, and add the forward-record requirement before any money is attached.
