Headline. The model is informative and the leaderboard refuses to pay it. Out-of-sample Brier score is 0.2104 against a 0.2531 constant-home baseline (skill +0.173, permutation p = 0.0002), but with 96 graded games, an expected-calibration error of 0.104 and no official price archive, no strategy clears the pre-registered bar for a reward.
The largest verification result is not a model, it is a reconciliation. Summing the 121 committed final scores reproduces all 30 official win-loss records exactly. That is the check that makes the dataset trustworthy, because it compares two separately transcribed official tables rather than trusting either one.
The correlation that actually matters for pricing is not the one people assume. Within a game, margin and total are nearly independent (r = +0.035), so spread-plus-total same-game parlays barely move when dependence is accounted for. The material dependence is inside a player's own stat line: points and rebounds correlate at r = +0.268 on 1,951 within-player residuals, which lifts a two-leg prop combo by up to 0.05 in absolute probability versus pricing the legs as independent.

The verification contract

  1. One source per row. Every table row links to an official NBA page or to the committed data file it was computed from. verify.py fails the build otherwise.
  2. No inferred values. If an official page does not state it, the cell is blank and the item appears on the flagged page. Blank cells are never silently treated as zero.
  3. No self-graded edge. A model comparing its line to its own line is circular, so no ROI, no expected value and no closure-line value is claimed: there is no official price archive.
  4. Luck is measured, not asserted. Every skill number is accompanied by a paired bootstrap interval and a permutation test that shuffles the prediction-to-outcome assignment.

Rebuild everything with python3 collect_official.py && python3 engine.py && python3 audit.py && python3 build.py && python3 verify.py. The engine is seeded, so the numbers are byte-identical on re-run.

Research only — not wagering advice, and not a betting product. Every value on this site is either copied from an official NBA page or computed from committed data by a formula on the method page; anything that could not be verified is left blank and listed on Flagged for review.
