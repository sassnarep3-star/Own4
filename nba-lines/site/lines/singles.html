Singles: fair spread, total and moneyline

Tonight's two games priced from the rating and totals models, with the break-even probability behind every number.

These are fair prices, not edges. A fair price is the number at which the model believes a bet is worth exactly zero. Turning it into an edge requires a market price to compare against, and no official price archive exists in this repository (flag F01, gate G9).

Break-even probabilities

The probability that makes a bet at that price break even. Read this as the model's opinion of the true chance, not as a recommendation. Over/under at the fair total is exactly 50% by construction — that is what makes it the fair total.

How each number is built

margin_home = rating_home - rating_away + home_court
rating_i    = (sum_targets + lambda * prior_2025_26_i) / (games_i + lambda)      lambda = 12
            where target = opponent_rating + margin  (or opponent_rating - margin when away)
            iterated to convergence, then centred so the league mean rating is 0
total       = base + offset_home + offset_away                                   lambda = 12
P(home)     = Phi(margin_home / sigma_margin)                     sigma_margin = 13.716
fair ML     = -100p/(1-p) if p >= 0.5 else +100(1-p)/p
home total  = (mu_total + mu_margin)/2      away total = (mu_total - mu_margin)/2

Read the totals result honestly. The totals model scores a skill of +0.0201 against a constant-league-average baseline, and its bootstrap interval (-0.073 to +0.106) contains zero. On 96 games there is no evidence it beats just using the league average. The moneyline model is the one with a signal that survives its interval.
