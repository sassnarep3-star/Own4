Data policy

The league's FAQ states that its statistics "are not available for download for either academic or personal use". This release therefore contains no bulk extract of league data. What it contains is 30 standings rows, 121 final scores, 2 slate entries and 13 availability rows, each read from a publicly displayed page and stored with the exact URL. The one large third-party extract already in the repository (47 MB of partner box scores) predates this session and is flagged under R05 rather than extended.

Reproduce

cd nba-lines
python3 collect_official.py   # transcription register -> data/*.json
python3 engine.py             # model, correlations, backtest, gates, leaderboard
python3 audit.py              # repo review + flagged registers
python3 build.py              # 17 static pages + root landing page
python3 verify.py             # source links, internal links, blanks, determinism
python3 -m unittest discover -s tests -v

Standard library only, no network access, seeded randomness (seed = 20261105), so two runs produce identical output. A CI workflow re-runs the whole chain and fails on any diff.

Model, in one place

# ratings (points per game vs a league-average opponent)
target_home = margin + r_away - H          target_away = r_home + H - margin
r_i = (sum(targets_i) + 12 * prior_i) / (games_i + 12)       iterated 400x, then centred
H   = mean(margin - (r_home - r_away))                        re-estimated each iteration

# totals (additive, centred, shrunk toward the 2025-26 tendency)
total = base + off_home + off_away        off_i = (sum(totals - base - off_opp) + 12*prior_i)/(games_i+12)

# probabilities
P(home) = Phi(margin / sigma_margin)      sigma from walk-forward residuals
P(both) = bivariate normal with measured r(margin, total)

The prior is the 2025-26 per-game point differential from the official team-stats table; the totals prior is derived as 2*PTS - plus_minus minus the league mean, which reconstructs a team's average game total from two published columns.

Known weaknesses

  • Ninety-six graded games. Every interval on this site is wide, and the correct reading of a wide interval is 'unknown', not 'close to zero'.
  • No market prices, so no edge can be measured (F01, G9).
  • No injury, lineup or fatigue adjustment baked into the ratings — shown as context instead.
  • Prop volatility is pooled across players rather than estimated per player (F05).
  • The 2025-26 prior is an inherited transcription, internally consistent but not re-read this session (F11).

Method sources: NIST/SEMATECH, scikit-learn, calibration, Benjamini–Hochberg.
