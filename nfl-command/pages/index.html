How to review this site

  • Requirements traceability - every requirement in the brief, where it is implemented and whether it is met.
  • Decision register - what was decided, what is still unknown and how to find out.
  • Suggestions - eight options with evidence, risk and prerequisites. None of them is approved.
  • Flagged for review - every irregularity, unverified value and open item.
  • Repository audit - all 927 files outside this namespace, with a manual review link for each.
  • Methodology - the model, the gates, the pre-registration and the price audit.

Source policy. Official values link to nfl.com. Third-party values link to the named archive and say so in the column header. A value that no official source confirms is left blank and marked unverified.

Responsible gambling. No strategy on this site is a recommendation to bet. No betting strategy passes the validation gates, so nothing here is activated. If gambling is a problem, contact the National Council on Problem Gambling helpline on 1-800-522-4700, or ncpgambling.org.
