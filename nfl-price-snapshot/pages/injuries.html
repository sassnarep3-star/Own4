Injuries & replacement depth

Official Week 10 injury designations from nfl.com. The system tracks injuries and knows that replacements matter — but the NFL publishes no depth chart (nfl.com/depth-charts/ returns a 404) and no snap counts, so no 1st/2nd/3rd/4th-string label can be sourced and no replacement depth can be measured. Only official game-status designations are published.

What the brief asks for that does not exist

The brief asks for defensive/offensive deficiencies tracked as “2nd, 3rd or 4th string backups replacing starters”. Because no official depth chart or snap-count feed exists, any string label would be invented — so none is published. What is published instead: the official game-status designation for every affected player captured, and the honest statement that replacement depth is blocked (flag F-02 / F-03 / F-05).
