Injury surprise — structurally blank

The brief asks for a surprise, never a level. A surprise is observed minus expected for the same player. This season has one dated availability snapshot in this workspace, so there is no expected value to subtract. All 347 surprise cells are therefore blank rather than estimated from a single reading (F-08).
