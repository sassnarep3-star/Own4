How to check any row on this site

Every table row links to either an official page or a repository file. For a number taken from a repo artefact, the artefact path is on the row and the file can be opened directly. For a number taken from an official page, the page is linked and the exact section is named in the evidence column of the repo-review or readiness table. If a row cannot be traced that way, it is a defect — flag it and it will be fixed rather than argued with.
